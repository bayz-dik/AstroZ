# Arah desain AstroZ

Aturan tampilan sekarang ada di satu tempat:

- `design-systems/claude-code/DESIGN.md` untuk aturan dan alasan.
- `design-systems/claude-code/tokens.css` untuk nilai tokennya.
- `design-systems/claude-code/source/evidence.md` untuk asal setiap nilai.

Ringkasnya: ruang kerja hangat ala Claude Code. Kanvas perkamen `#FAF9F5`
(atau arang hangat `#262624` di tema gelap), satu aksen terracotta, netral
serba hangat tanpa abu biru, kedalaman memakai cincin bukan bayangan, radius
8/12/16px, judul serif Fraunces bobot 500, teks Inter, angka dan kode
JetBrains Mono.

Berkas ini dulu memuat arah cetak Swiss (kertas putih, radius 0, Archivo dan
DM Mono). Arah itu sudah diganti; kalau ada bagian UI yang masih mengikutinya,
itu sisa yang belum dibersihkan.
